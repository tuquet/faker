# Tuquet Faker

> Enterprise-grade synthetic persona, National ID, payment card, and identity test data generator in Rust.

Official Documentation & Guides: **[https://docs.tuquet.com/en/cli/faker/](https://docs.tuquet.com/en/cli/faker/)**

---

## Installation & Usage

Generate synthetic identities using the Tuquet CLI:

```powershell
tq faker generate --nationality VN
```
